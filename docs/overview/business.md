## 三、生信分析服务

### 定位

面向有生物信息学数据分析需求的科研用户，提供**专业化数据分析服务**，涵盖从数据质控到深度解读的全流程。

### 服务方向

#### 转录组分析

| 服务项 | 说明 |
|---|---|
| RNA 测序差异表达分析 | 差异基因鉴定、火山图/热图输出、功能解读 |
| 可变剪接分析 | 差异剪接事件检测与注释 |
| 加权基因共表达网络分析 | 模块化分析，关键模块与表型关联，Hub 基因鉴定 |
| 单细胞 RNA 测序分析 | 质控、降维聚类、细胞类型注释、拟时序分析 |
| 空间转录组数据分析 | 空间基因表达可视化与区域特征分析 |

#### 基因组分析

| 服务项 | 说明 |
|---|---|
| 全基因组关联分析（GWAS） | 基因型-表型关联分析、显著位点注释 |
| 变异检测与注释 | SNP / InDel 检测，功能影响预测 |
| 基因组组装质量评估 | 完整性评估、组装统计、基因组大小估算 |
| 比较基因组分析 | 基因家族扩张收缩、共线性分析、物种分化时间估算 |
| 转座子与重复序列注释 | 全基因组重复序列鉴定与分类 |

#### 蛋白质分析

| 服务项 | 说明 |
|---|---|
| 蛋白质结构预测与分析 | 三维结构预测，输出结构文件及可视化报告 |
| 蛋白质功能注释 | 结构域分析、功能位点预测、信号肽/跨膜区预测 |
| 蛋白质相互作用网络分析 | PPI 网络构建，关键节点 Hub 蛋白挖掘 |
| 蛋白质序列比对与进化分析 | 多序列比对，系统发育树构建 |
| 分子对接辅助分析 | 配体-受体对接参数整理、结合自由能评估 |

#### 宏基因组 / 微生物组分析

| 服务项 | 说明 |
|---|---|
| 16S rRNA 扩增子分析 | 物种聚类、多样性评估、物种组成可视化 |
| 宏基因组 Shotgun 分析 | 物种注释、功能注释、宏基因组组装 |
| 宏转录组分析 | 活性微生物群落功能基因表达谱分析 |

#### 甲基化分析

| 服务项 | 说明 |
|---|---|
| 差异甲基化分析 | 甲基化位点鉴定与差异分析 |
| 功能富集与关联分析 | 甲基化与基因表达关联，通路富集 |

#### 数据挖掘与生物标志物

| 服务项 | 说明 |
|---|---|
| 通路富集分析 | 差异基因/蛋白功能注释，富集图表输出 |
| 机器学习生物标志物筛选 | 特征筛选、模型评估、临床预测模型构建 |
| 生存分析与临床数据挖掘 | 生存曲线、风险回归、公共数据集二次分析 |
| 细胞通讯分析 | 推断细胞间配体-受体相互作用网络 |

### 收费模式

- 按服务项目人工报价，结合数据量、分析复杂度及交付时限分档定价
- 标准分析项目（如 RNA-seq 差异分析）可提供固定价格套餐，降低用户决策门槛
- 持有效会员可享折扣（与其他付费业务统一折扣体系）
- 业务流程：用户咨询 → 确认需求与报价 → 线下支付或订单系统支付 → 分析交付

### 交付物

- 专业分析报告（含结果解读与图表）
- 原始分析结果数据
- 是否随报告提供分析脚本（待决策）

## 四、可视化服务

### 4.1 基础制图

#### 定义

系统提供标准化图表模板（热图、火山图、箱线图、生存曲线、等高线、三元图、PCA 图、雷达图等 400+ 图表类型），用户上传数据后在线自助生成，**实时出图，无需人工介入**。

#### 页面形态

- **图表类型展示页**：以画廊形式展示全部可用图表类型，每种图表含缩略图、名称、说明及分类标签，引导用户进入制图工具
- **制图工具页**：用户选择图表类型 → 上传数据文件（支持 CSV/TSV/Excel）→ 调整参数（配色方案、字号、尺寸等）→ 实时预览 → 导出下载

#### 收费策略

基础制图功能**当前阶段永久免费**，所有用户（含游客）均可无限制使用。

> **与会员系统的绑定：** 基础制图功能与会员体系保持关联设计。未来随平台发展，可能逐步调整为仅限会员使用（如限制游客/非会员的使用次数或图表类型范围），届时可通过后台配置灵活切换，无需重新设计权限架构。

### 4.2 个性化制图

#### 定义

不适合标准模板的复杂需求，由团队成员提供**专属人工 1v1 服务**，包括但不限于：进化树、基因结构图、序列 Logo、复杂组合图、排版美化等。

#### 页面形态

独立页面或与基础制图同页 Tab 切换（待定），页面内容：
- 服务说明、效果范例画廊
- 定价参考（区间价 / 工作量分档，如基础款 / 进阶款 / 复杂款）
- CTA 按钮引导用户通过**微信 / 表单**联系团队

#### 业务流程

1. 用户在页面浏览范例 & 定价参考
2. 用户通过页面表单或微信联系团队，描述需求
3. 团队评估工作量，与用户 1v1 确认需求细节及最终报价
4. 用户通过线下转账或订单系统完成支付
5. 团队制作完成后交付成品，用户确认验收

**关键设计要点：**
- 需求和价格须经人工确认后才进入支付流程
- 作品交付通过限时有效链接或线下发送
- 用户可在「我的订单」查看历史订单和下载入口（订单系统上线后）

## 七、行业咨询（收费增值服务）

### 定位

面向有深度科研需求的用户，提供**付费的专业化 1v1 咨询服务**，核心差异点是「有明确产出物或解答」，而非简单的客服回复。

### 服务方向

| 服务类型 | 说明 | 参考收费模式 |
|---|---|---|
| 统计方法学咨询 | 实验设计、样本量计算、统计分析方法选择建议 | 按次（30 / 60 分钟视频 / 文字咨询） |
| 数据分析诊断 | 上传数据，专家给出分析报告或方向建议 | 按次，按数据复杂度分档 |
| 图表方案设计 | 针对特定论文 / 汇报场景，给出制图方案建议（不含制图本身） | 按次 |
| 科研思路梳理 | 课题方向、实验路线讨论 | 按次（时间计费）|

### 收费模式

- **按次定价**：固定价格对应固定服务内容（最易理解，转化率高）
- **套餐包**：如「3 次咨询包」打折购买（提升客单价和复购）
- **会员折扣**：持有效会员可享咨询服务折扣（增强会员吸引力）

### 业务流程

页面展示服务介绍 & 定价 → 用户自助下单支付（固定定价服务）或联系后台报价（复杂定制咨询）→ 咨询交付（视频 / 文档 / 报告） → 用户评价。

> **待决策：** 具体服务项目与定价、是否支持用户自助预约（含日历选时功能）、是否录制视频存档供用户回看。

## 十、支付与订单体系

### 阶段规划

| 阶段 | 收费方式 | 说明 |
|---|---|---|
| **前期（当前）** | 线下支付 | 用户通过支付宝 / 微信个人转账完成付款，运营人员手动确认并记录 |
| **中后期** | 在线支付 + 订单系统 | 接入正式支付渠道，订单全流程线上化管理 |

### 线下支付阶段流程

1. 用户与团队确认服务内容与价格
2. 用户通过支付宝或微信向指定账户转账
3. 运营人员确认收款后，手动开始服务
4. 服务完成后通过微信/邮件等方式交付成品

### 在线订单系统（中后期）

所有付费服务（个性化制图、生信分析、学术服务、行业咨询、会员购买）统一走订单流程：

**订单生命周期：**

```
创建 → 待支付 → 已支付 → 制作中 → 已完成 → 已交付
```

**订单分类：**
- **自助订单**：用户直接选择套餐/档位支付（会员购买、固定定价咨询等）
- **人工订单**：运营人员与用户确认需求后，后台创建订单推送给用户支付（个性化制图、生信分析、学术服务等）

### 支付渠道（中后期）

以**个体工商户**身份直连官方支付渠道：
- 微信支付
- 支付宝

> 无需第三方聚合支付平台，直连官方渠道，费率最优。

### 各业务收费方式总览

| 业务模块 | 收费方式 |
|---|---|
| 基础制图 | 永久免费（未来可能调整为会员专属） |
| 个性化制图 | 人工报价，按工作量分档（基础款 / 进阶款 / 复杂款） |

## 十一、促销活动体系

> 促销作为平台统一赋能模块，可影响全局所有付费业务（个性化制图、生信分析、学术服务、行业咨询、会员购买等），不局限于某一业务板块。

### 促销能力

- 订单内置促销字段（原价、折扣金额、优惠券码、关联活动）
- 后台可配置促销活动，活动上线仅需后台操作，无需改动系统

### 后台可配置项

- 活动名称、有效期（起止时间）
- 适用范围（全部业务 / 指定业务模块 / 指定会员档位）
- 折扣方式：折扣率（如 8 折）或直减金额（如减 10 元）
- 是否叠加优惠券

### 页面展示规范

| 场景 | 展示方式 |
|---|---|
| 有进行中活动 | 价格区域显示折扣价（高亮）+ 原价划线，角标「限时优惠」 |
| 活动倒计时 | 可选：展示剩余时间（适合短期秒杀活动） |
| 游客状态 | 展示活动价，CTA「登录后立即享优惠」 |
| 非会员状态 | 展示活动价 + 划线原价 |
| 有效会员 | 显示「已享会员权益」，无需再展示活动价 |

### 阶段说明

- **前期（线下支付阶段）**：促销活动通过运营人员手动计算折扣并告知用户，暂不依赖系统自动化
- **中后期（订单系统上线后）**：促销规则由系统自动应用，订单自动计算折扣金额
