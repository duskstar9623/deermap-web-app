## 三、基础制图

### 定义

系统提供标准化图表模板（热图、火山图、箱线图、生存曲线、等高线、三元图等），用户上传数据后在线自助生成，**实时出图，无需人工介入**。

### 页面形态

独立的制图工具页面（`/charts/basic`），用户选择图表类型 → 按提示上传数据文件 → 在线预览并下载。

### 收费模式与权益分层

| 用户状态 | 制图权限 | UI 说明 |
|---|---|---|
| **游客（未登录）** | 每自然日 1 次免费出图 | 出图后显示「今日免费次数已用完，登录后继续使用」；次日自动重置 |
| **已登录 · 非会员** | 按单次付费 | 价格标签显示原价，支持单次购买；活动期间可展示折扣价 + 划线价 |
| **已登录 · 有效会员** | 无限次免费基础制图 | 显示「会员专属」标记，无数量提示 |

#### 游客免费次数 — 技术检测机制

> 目标：低成本阻断滥用，同时对正常用户无感知。无需做到完全防刷，只要提高滥用门槛即可。

**检测策略（多维组合、后端校验）：**

| 维度 | 实现方式 | 说明 |
|---|---|---|
| 浏览器指纹 | `FingerprintJS`（开源版）生成设备指纹，随请求发送至 BFF | 覆盖换 IP / 无痕模式等常见规避手段 |
| IP 地址 | BFF 层读取真实 IP（`X-Forwarded-For`，配合 Nginx 信任代理配置） | 辅助判断，不单独作为限制依据（NAT 共享 IP 会误伤） |
| Cookie / LocalStorage | 前端写入首次使用标记（`bio_guest_used_YYYYMMDD`），BFF 同步验证 | 最轻量，易被清除，仅作为第一道拦截 |
| Redis 计数 | 以「设备指纹 + 当日日期」为 Key，写入 Redis，`EXPIRE` 到次日 00:00 | **主要判断依据**，服务端不可绕过 |

**流程：**
```
游客点击出图
    │
    ▼
前端发送 { fingerprint, date } 给 BFF /api/charts/basic/guest-check
    │
    ▼
BFF 查询 Redis Key: guest:{fingerprint}:{date}
    ├── 不存在 → 允许出图，写入 Key（SET NX，EXPIRE 至次日 0 点）
    └── 已存在 → 返回 429，前端弹登录引导弹窗
```

#### 模式 A：会员制

| 会员周期 | 说明 |
|---|---|---|---|
| 单日会员 | 当日内无限次基础制图 |
| 月会员 | 自然月内无限次基础制图 |
| 季会员 | 90 天内无限次基础制图 |
| 年会员 | 365 天内无限次基础制图 |

- 会员期间基础制图**免费、无次数限制**
- 会员权益仅限基础制图，个性化制图另行计费（持有效会员可享折扣）

#### 模式 B：按次收费（无会员）

- 非会员登录用户按单次基础制图收费
- 具体单价待定（需结合成本和市场调研确定）

#### 促销活动设计

> 系统需在订单模型和 UI 层内置促销支持，确保活动上线无需改代码，只需后台配置。

**数据模型层（`orders` 表）：**
- `original_price`：原价
- `discount_amount`：折扣金额
- `coupon_code`：优惠券码（可为空）
- `promotion_id`：关联活动 ID（可为空）

**后台配置（Payload CMS / NestJS `promotions` 模块）：**
- 活动名称、有效期（起止时间）
- 适用范围（全部会员档位 / 指定档位 / 单次制图）
- 折扣方式：折扣率（如 8 折）或直减金额（如减 10 元）
- 是否叠加优惠券

**UI 展示规范：**

| 场景 | 展示方式 |
|---|---|
| 有进行中活动 | 价格区域显示折扣价（高亮）+ 原价划线，角标「限时优惠」 |
| 活动倒计时 | 可选：展示剩余时间（适合短期秒杀活动） |
| 游客状态 | 展示活动价，CTA「登录后立即享优惠」 |
| 非会员状态 | 展示活动价 + 划线原价 |
| 有效会员 | 显示「已享会员权益」，无需再展示活动价（避免自相矛盾） |

## 四、个性化制图

### 定义

不适合标准模板的复杂需求，由团队成员提供**专属人工 1v1 服务**，包括但不限于：进化树、基因结构图、序列 Logo、复杂组合图、排版美化等。

### 页面形态

独立页面（`/charts/custom`），或与基础制图同页 Tab 切换（待定），页面内容：
- 服务说明、效果范例画廊
- 定价参考（区间价 / 工作量分档，如基础款 / 进阶款 / 复杂款）
- CTA 按钮引导用户通过**微信 / 表单**联系团队

### 推荐业务流程

```
1. 用户在页面浏览范例 & 定价参考
        │
        ▼
2. 用户通过页面表单或微信联系团队，描述需求
        │
        ▼
3. 团队评估工作量，与用户 1v1 微信确认需求细节及最终报价
        │
        ▼
4. 【后台操作】运营人员在管理后台为该用户账号创建专属订单
   - 填写：用户账号、服务描述、价格、预计交付时间
   - 系统生成唯一订单号，订单状态设为「待支付」
        │
        ▼
5. 【系统通知】站内消息 + 微信服务号模板消息推送给用户
   - 内容：「您的定制制图订单已生成，请前往 [订单页] 完成支付」
        │
        ▼
6. 用户登录账号，在「我的订单」页查看并发起支付
   （微信支付 / 支付宝，走正式商户 APIv3 接口）
        │
        ▼
7. 支付成功 → Webhook 回调 → 订单状态更新为「已支付 · 制作中」
        │
        ▼
8. 运营人员完成制图 → 上传成品到 OSS
   → 后台标记「已完成」→ 通知用户下载（签名 URL，限时有效）
```

**关键设计要点：**
- 订单由**后台主动创建**（非用户自助下单），确保价格和描述经人工确认后才进入支付流程
- 付款流程复用基础制图的订单 + 支付模块，无需单独开发
- 作品交付通过 OSS 签名 URL，避免资源泄露，链接有效期可配置（如 72 小时）
- 用户可在「我的订单」随时查看历史订单和下载入口

## 五、用户系统

## 七、生信业务

> 独立页面（`/bioinformatics`），面向有生物信息学数据分析需求的科研用户，提供**专业化数据分析服务**，以人工报价 + 后台创建订单 + 在线支付流程交付。

### 服务方向

#### 蛋白质分析

| 服务项 | 说明 |
|---|---|
| 蛋白质结构预测与分析 | 基于 AlphaFold2 / ESMFold 进行三维结构预测，输出 PDB 文件及可视化报告 |
| 蛋白质功能注释 | 结构域分析（Pfam / InterPro）、功能位点预测、信号肽 / 跨膜区预测 |
| 蛋白质相互作用网络分析 | PPI 网络构建（STRING / BioPlex），关键节点 Hub 蛋白挖掘 |
| 蛋白质序列比对与进化分析 | 多序列比对（MUSCLE / MAFFT），系统发育树构建（IQ-TREE / MEGA） |
| 分子对接辅助分析 | 配体-受体对接参数整理、结合自由能评估数据解读（AutoDock / Rosetta） |

#### 基因组分析

| 服务项 | 说明 |
|---|---|
| 全基因组关联分析（GWAS） | 基因型-表型关联分析、曼哈顿图 / QQ 图绘制、显著位点注释 |
| 变异检测与注释 | SNP / InDel 检测（GATK），功能影响预测（ANNOVAR / SnpEff） |
| 基因组组装质量评估 | BUSCO 完整性评估、N50/L50 统计、基因组大小估算 |
| 比较基因组分析 | 基因家族扩张收缩（CAFÉ）、共线性分析（MCScanX / JCVI）、物种分化时间估算 |
| 转座子与重复序列注释 | RepeatMasker / RepeatModeler 全基因组重复序列鉴定与分类 |

#### 转录组分析

| 服务项 | 说明 |
|---|---|
| RNA-seq 差异表达分析 | 读段比对、定量（STAR + featureCounts / Salmon），DESeq2 / edgeR 差异分析，火山图 / 热图输出 |
| 可变剪接分析 | rMATS / SUPPA2 检测差异剪接事件，注释与可视化 |
| 加权基因共表达网络（WGCNA） | 模块化分析，关键模块与表型关联，Hub 基因鉴定 |
| 单细胞 RNA-seq 分析（scRNA-seq） | 质控（Seurat / Scanpy）、降维聚类、细胞类型注释、拟时序分析（Monocle / scVelo） |
| 空间转录组数据分析 | 10x Visium / Stereo-seq 数据处理，空间基因表达可视化 |

#### 宏基因组 / 微生物组分析

| 服务项 | 说明 |
|---|---|
| 16S rRNA 扩增子分析 | OTU/ASV 聚类（QIIME2 / DADA2），Alpha/Beta 多样性，物种组成可视化 |
| 宏基因组 Shotgun 分析 | 物种注释（MetaPhlAn）、功能注释（HUMAnN）、宏基因组组装（MEGAHIT） |
| 宏转录组分析 | 活性微生物群落功能基因表达谱分析 |

#### 多组学整合与数据挖掘

| 服务项 | 说明 |
|---|---|
| 通路富集分析（GO / KEGG / GSEA） | 差异基因/蛋白功能注释，富集气泡图 / 条形图 / 网络图输出 |
| 多组学整合分析 | 转录组 + 蛋白组 / 代谢组联合分析，MOFA / iClusting 多组学降维整合 |
| 机器学习生物标志物筛选 | 基于 LASSO / 随机森林 / SVM 进行特征筛选，ROC 曲线评估，临床预测模型构建 |
| 生存分析与临床数据挖掘 | Kaplan-Meier 生存曲线、Cox 回归、TCGA / GEO 公共数据集挖掘与二次分析 |
| 细胞通讯分析 | CellChat / NicheNet 推断细胞间配体-受体相互作用网络 |

## 八、行业咨询（收费增值服务）

> 独立页面（`/consulting`），细节待定，以下为建议方向。

### 定位

面向有深度科研需求的用户，提供**付费的专业化 1v1 咨询服务**，核心差异点是「有明确产出物或解答」，而非简单的客服回复。

### 建议服务方向

| 服务类型 | 说明 | 参考收费模式 |
|---|---|---|
| 统计方法学咨询 | 实验设计、样本量计算、统计分析方法选择建议 | 按次（30 / 60 分钟视频 / 文字咨询） |
| 数据分析诊断 | 上传数据，专家给出分析报告或方向建议 | 按次，按数据复杂度分档 |
| 图表方案设计 | 针对特定论文 / 汇报场景，给出制图方案建议（不含制图本身） | 按次 |
| 科研思路梳理 | 课题方向、实验路线讨论 | 按次（时间计费）|

### 推荐收费模式

- **按次定价**：固定价格对应固定服务内容（最易理解，转化率高）
- **套餐包**：如「3 次咨询包」打折购买（提升客单价和复购）
- **会员折扣**：持有效会员可享咨询服务折扣（增强会员吸引力）

### 业务流程

复用个性化制图的流程框架：页面展示服务介绍 & 定价 → 用户自助下单支付（固定定价服务）或联系后台报价（复杂定制咨询）→ 咨询交付（视频 / 文档 / 报告） → 用户评价。

> **待决策：** 具体服务项目、定价、是否支持用户自助预约（含日历选时功能）、是否录制视频存档供用户回看。
